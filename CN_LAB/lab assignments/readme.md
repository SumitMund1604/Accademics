# Cisco Packet Tracer Networking Assignments

This repository contains a collection of Cisco Packet Tracer (`.pkt`) lab files demonstrating fundamental networking concepts, from basic topologies to advanced routing and server configurations. 

##  Project Files Directory

Below is a list of the included Packet Tracer files and a brief description of what each demonstrates based on the lab assignments:

| File Name | Corresponding Topic | Description |
| :--- | :--- | :--- |
| `basic switch and hub connection.pkt` | Assignment 5 | A simple LAN setup demonstrating how a Hub and Switch handle traffic and collisions. |
| `topologies.pkt` | Assignment 6 | Demonstrations of Star, Ring, Bus, Mesh, and Hybrid network topologies. |
| `router setup cli.pkt` | Assignment 7 | Configuring a router  and setting up multiple interfaces using the Command Line Interface. |
| `dhcp with a server and switch.pkt` | Assignment 8 | Setting up a dedicated Server-PT to act as a DHCP server for a local network. |
| `dhcp with router.pkt` / `dhcp with router and server.pkt` | Assignment 9 (Part 1) | Configuring a Cisco router to act as a DHCP server for connected PCs. |
| `ftp http dns dhcp.pkt` | Assignment 9 (Part 2) | Configuring a Server with FTP, HTTP (Web), and DNS services alongside DHCP. |
| `email confi.pkt` | Assignment 10 | Setting up an Email server (SMTP/POP3) and configuring clients to send and receive emails. |
| `t2.pkt` | Assignment 11 | (Static Routing) Configuring 2 routers and routing tables to connect two distinct LANs. |
| `vlan.pkt` | Assignment 12 | Configuration of Virtual Local Area Networks to segment broadcast domains. |
